# Roadmap

## Fáze 1 – základ
- [x] Návrh adresářové struktury a metodických pravidel.
- [x] Založení repozitáře.
- [ ] Nahrát a zkontrolovat úplnou kostru.

## Fáze 2 – finanční PDF
- [ ] Sepsat inventář dostupných dokumentů.
- [ ] Doplnit originální PDF do příslušných ročníků.
- [ ] Doplnit metadata a kontrolní SHA-256.
- [ ] Rozlišit strojově čitelná PDF a skeny.

## Fáze 3 – extrakce a kontrola
- [ ] Připravit skript pro extrakci textu/tabulek.
- [ ] Přidat OCR fallback pro skeny.
- [ ] Vytvořit report kvality a validační kontroly.
- [ ] Pilotně ověřit rok 2024.

## Fáze 4 – integrace a web
- [ ] Připravit stabilní datový kontrakt.
- [ ] Napojit ověřené výstupy veřejných zakázek.
- [ ] Napojit veřejně dostupná dotační data.
- [ ] Vytvořit finanční přehledy a zdrojové odkazy.
